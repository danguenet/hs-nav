# Security Policy

## Supported version

Only the latest version available from the Chrome Web Store is supported with fixes.

## Reporting a concern

Do not open a public issue for a security or privacy concern. Email [dan@performancerevops.com](mailto:dan@performancerevops.com) with:

- the affected HS Nav version;
- a clear description and impact;
- minimal reproduction steps or a proof of concept; and
- any suggested remediation, if available.

Remove HubSpot credentials, account data, private URLs, and personal information from the report unless they are essential to understanding the concern. Reports will be acknowledged and assessed on a best-effort basis. This project does not currently operate a paid bug-bounty program.
