# Support

## Usage questions

Search existing [GitHub Discussions](https://github.com/danguenet/hs-nav/discussions) before starting a new discussion. Include your Chrome version, extension version, and the behavior you expected.

## Bugs and route problems

Use the repository's [issue templates](https://github.com/danguenet/hs-nav/issues/new/choose):

- **Bug report** for reproducible extension behavior.
- **Route report** for a missing, stale, or incorrect HubSpot destination.
- **Feature request** for a proposed improvement.

Do not include HubSpot account data, credentials, private URLs, or other sensitive information. Support is provided on a best-effort basis without a guaranteed response time.

## Private reports

Security and privacy concerns must be sent privately as described in [SECURITY.md](SECURITY.md), not posted in issues or discussions.
